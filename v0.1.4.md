# v0.1.4

You can now save tasks you'll do again, talk to the agent, and use it across multiple Chrome profiles.
This release also fixes a few things that got in the way while working with tabs and chats.

## What's new

- **Save as a task:** Turn a useful conversation into a task you can run again.
  Review the instructions before saving, then use `/tasks` whenever you need it.
- **Voice input:** Click the microphone and say what you need.
  Use browser dictation or bring your own key for Groq, OpenRouter, Deepgram, or ElevenLabs.
  You can edit the text before sending it and change your provider or model with `/voice-config`.
- **Multiple Chrome profiles:** Use the agent in different profiles at the same time, with one DSH instance running.
- **Background notifications:** If an agent working in the background needs an answer or approval, you'll get a Chrome notification to return to that chat.
  Use `/notifications` to turn the sound on or off.
- **Approval toggle:** Use `/human-in-the-loop` to turn approval prompts on or off for the current chat.
- **Memory benchmark:** Run `pnpm benchmark:memory` to see how Chrome and DSH memory changes while agents work across tabs.
  It includes a guided setup and a report you can open afterward.

## Things that work better now

- The agent has retry limits so it doesn't keep repeating the same failed action.
- Better handling of page changes and stale element references, along with improved discovery of elements inside shadow DOM.
- Saved chats return to their tabs more reliably, including reopening a tab you've closed.
- Saved-task generation handles incomplete model responses better.
- Clearer provider errors, including when an OpenRouter key reaches its spending limit.
- Fixed Markdown tables and kept the side-panel header visible while scrolling.
- Made the screenshot drop area easier to use.
- Renamed `/actions` to `/tools` and improved the slash-command and theme pickers.

## Updating

Stop DSH, run the installer again, and reload the extension at `chrome://extensions`.
If you use multiple Chrome profiles, reload it in each one, then start DSH again.
Your settings are kept.
